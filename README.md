# Portfolio_Meng-Yuan
本作品集聚焦国际市场研究、舆情与风险分析、行业竞争动态及企业传播策略，展示我在复杂信息中识别关键问题、形成分析判断，并将研究发现转化为策略建议的实践经历。

关于我

我具备传播学专业背景，拥有国际公关公司实习及海外学习经历，关注公共事务、企业声誉与国际传播。
在伟达公关实习期间，我支持伊利、隆基绿能、东芝等客户的海外传播工作，涉及国际竞品分析、跨市场舆情研究、政策法规与文化风险评估、媒体资源拓展及年度声誉传播规划。
相关工作让我积累了多渠道信息搜集、行业案例分析、风险因素梳理及策略建议输出的经验。我重视信息来源与分析逻辑，也关注不同政策、文化和舆论环境对企业经营及外部沟通的影响。

核心项目

01. 伊利沙特市场进入与上市传播支持

研究方向： 国际市场环境 · 政策法规与文化风险 · 舆情分析

收集国际食品企业在中东及印尼市场的典型舆情案例，从地缘政治、政策法规、宗教文化、营商环境及媒体倾向五个维度开展风险评估，为伊利沙特上市及相关市场传播策略提供研究支持。

项目成果： 评估结论及传播建议均被客户采纳，并用于指导相关市场的整合传播策略。

02. 伊利海外竞品分析与声誉传播策略

研究方向： 行业动态追踪 · 竞品分析 · 策略建议

独立完成 4 份月度竞品分析报告，研究伊利与雀巢、玛氏等企业的国际传播动态，累计提出 12–15 条传播建议，其中 8–12 条被客户采纳，并通过 PPT 向客户团队进行月度汇报。

03. 伊利美国市场媒体研究与渠道评估

研究方向： 媒体环境分析 · 信息筛选 · 传播渠道研究

梳理并对接 16 家美国华人微信公众号媒体，利用清博数据分析粉丝规模与阅读表现，并结合媒体反馈优化传播角度，支持伊利新闻稿在海外华文媒体渠道的精准投放。
